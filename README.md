# Evy Braids

Revisão do projeto original https://github.com/druzinho/evybraids, baseada na versão 4f7c31d.

## Alterações

- Fotos com caminhos corrigidos e versões WebP cerca de 61% menores.
- Layout adaptado para celular, tipografia e espaçamento revisados.
- Formas flutuantes com profundidade e transições discretas.
- Inclinação dos cartões apenas com mouse; preferência por movimento reduzido respeitada.
- Navegação entre seções corrigida e perguntas frequentes expansíveis.
- Contato pelo Instagram oficial informado no portfólio. O WhatsApp fictício foi removido.

## Visualização e publicação

Abra index.html para visualizar ou sirva esta pasta com um servidor HTTP estático.
Para publicar no GitHub Pages existente, envie index.html, style.css, script.js e os oito arquivos .webp para a raiz do repositório. As fotos .jpg originais podem ser mantidas.
Não exige instalação de pacotes nem etapa de compilação. As fontes do Google têm alternativas locais caso a conexão falhe.

## Verificação

Conferência visual da abertura no computador e em largura de celular de 390 px. Verificação estática de imagens, dimensões, links internos, destinos de contato e sintaxe JavaScript. Ainda é recomendável testar em aparelhos reais antes da publicação.

Esta cópia local não altera automaticamente o repositório nem o site publicado.
